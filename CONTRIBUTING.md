# Contributing

Open a pull request that adds one entry in the right section. An entry needs:

- A working link, and the source or store page of the project itself (no link shorteners, no re-hosts).
- One line saying what it is, in plain words.
- Active maintenance, or a clear reason to list it anyway.
- Disclosure if you are affiliated with the entry.

Not accepted: cracked or leaked resources, escrow bypasses, mass-generated listings, and anything that sells downloads from other authors without their permission.
